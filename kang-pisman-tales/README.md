# Kang Pisman Tales

Prototipe game edukasi pemilahan sampah Kota Bandung.

## Pasang
    npm install

## Build
    npm run build

## Jalankan
    npm run serve
Lalu buka http://localhost:8080

## Struktur
- `src/core` konfigurasi, utilitas, audio
- `src/data` palet, sprite, peta, gacha (JSON)
- `src/render` cache sprite, ubin, efek, draw
- `src/systems` dunia, pemain, gacha, UI
- `dist/index.html` hasil build untuk diserahkan

Jangan mengedit `dist/` secara langsung.
