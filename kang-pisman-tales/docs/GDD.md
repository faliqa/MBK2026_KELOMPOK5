# GDD - Kang Pisman Tales: Penjaga Bumi Parahyangan

## Ringkasan
Game edukasi top-down 2D. Pemain memilah 3 jenis sampah di 9 lokasi Bandung,
mengolahnya di 3 pabrik, lalu menarik gacha untuk mempercantik kota.

## Target
Sosialisasi pemilahan sampah untuk pelajar. Sesi 10-20 menit.

## Loop inti
Jelajah lokasi -> pungut sampah -> olah 3 sampah di pabrik -> gacha -> dapat item.

## Tabel rarity
| Rarity | Peluang | Kategori |
|---|---|---|
| Common | 45% | Pajangan |
| Uncommon | 28% | Pajangan |
| Rare | 15% | Buff |
| Epic | 7% | Buff |
| Legend | 3.5% | Pengumpul otomatis |
| Mythic | 1.5% + pity 12 | Pengumpul otomatis |

## Kondisi menang
Koleksi ketiga item Mythic (Organik, Anorganik, B3).

## Peta
1 Lobby + 3 Pabrik + 9 Zona = 13 area.
